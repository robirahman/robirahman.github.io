# robirahman.github.io

This repository contains the source code for my personal website built using the [al-folio](https://github.com/alshedivat/al-folio) theme. The site is deployed via GitHub Pages at [https://www.robirahman.com/](https://www.robirahman.com/).

## Site Sections

- **About** — homepage with bio and contact info
- **CV** — education, experience, and skills timeline
- **Projects** — portfolio of software projects
- **Travel** — travel map and visited locations
- **Tournaments** — chess tournament tracker
- **[Learn Bengali](https://www.robirahman.com/bengali/)** — interactive offline-first Bengali learning app
- **[Data Science](https://www.robirahman.com/data_science/)** — statistics and ML reference app
